// 02 — about.md

Halo, saya Iwan.

Saya seorang Mobile Application Developer yang berbasis di Wonogiri, Jawa Tengah, dengan 5+ tahun pengalaman merancang, membangun, dan merilis aplikasi Android menggunakan Flutter dan Dart — mulai dari wireframe pertama hingga rilis resmi di Play Store.

Pekerjaan saya mencakup seluruh siklus rilis: implementasi UI/UX, integrasi REST API, state management dengan GetX, hingga mengelola proses rilis end-to-end — build APK/AAB, versioning, store listing, sampai pemeliharaan pasca-rilis. Saya juga mengerjakan sisi web dan backend dengan Next.js, Laravel, dan Firebase ketika proyek membutuhkannya.

Saya lulusan S1 Informatika dari Universitas Amikom Yogyakarta, dan saya cukup peduli soal arsitektur yang bersih serta performa yang benar-benar terasa oleh pengguna.
